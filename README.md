# Page Distillery

> Turn abandoned reading into distilled wisdom elixirs.

A web app that captures articles you start but never finish into little glass flasks. Each flask loses its contents over time unless you actively distill, combine, or archive it. The result is a personal library of half-read internet wisdom rendered as useful, compact summaries.

## Features
- Capture an abandoned article into a glass flask with a reading-progress meter
- Flasks evaporate after 48 hours unless you pin, distill, or shatter them
- Merge two flasks into a single two-page summary elixir
- Export the distillate as an annotated PDF with source citations

## Stack
- React
- Firebase
- OpenAI

## Getting started
```
npm install, create .env with VITE_FIREBASE_* and VITE_OPENAI_KEY, then npm run dev
```
